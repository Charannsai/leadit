# Code of Conduct

We want Leadit to be a welcoming project for everyone, whatever their experience, background or identity.

## Expected behaviour

- Be kind and assume good intent.
- Give constructive, specific feedback on code and ideas, not on people.
- Respect different opinions and the time of maintainers and contributors.
- Help newcomers; everyone was new once.

## Not acceptable

- Harassment, insults, or discriminatory language or imagery.
- Personal attacks, trolling, or deliberately derailing discussions.
- Publishing anyone's private information (including lead data) without permission.
- Using the project's spaces to promote spam or unsolicited bulk outreach.

## Enforcement

Maintainers may remove comments, commits, issues or other contributions that break this code, and may temporarily or permanently ban anyone who does so.

Report problems privately to the maintainers by opening a [private security advisory](https://github.com/Charannsai/leadit/security/advisories/new) (it reaches maintainers only) or by contacting the repository owner on GitHub. Reports are handled confidentially.

This code is adapted in spirit from the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), which you can read for further guidance.
